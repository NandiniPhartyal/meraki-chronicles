# 📚 Meraki Chronicles – Official Club Website

## 🌟 Project Overview

**Meraki Chronicles** is the official website for the literary and creative expression club of our college. The platform serves as a digital hub where students can explore club activities, discover upcoming events, showcase their creative works, and connect with a community passionate about literature, storytelling, poetry, and public speaking.

This project has been developed as a **Frontend Development Subject Project** with the objective of creating a modern, responsive, and engaging user experience.

---

## 🎯 Objectives

* Create an online presence for Meraki Chronicles.
* Showcase the club's vision, mission, and activities.
* Promote events, competitions, and workshops.
* Provide a platform to display creative works such as poems, stories, articles, and spoken-word performances.
* Encourage student participation and community engagement.

## 🚀 Installation & Usage



